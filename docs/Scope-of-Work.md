# Scope of Work: Boardroom

## Room summary

A single, non-divisible boardroom with one 70-inch display, ceiling microphone and ceiling speakers. Users control the room from a 10-inch touch panel on the table. The room supports local presentation, audio calls and web conferencing through the room PC.

## Functions

| Function | Included |
|---|---|
| Presentation, wired and wireless | Yes |
| Web conferencing | Yes |
| Audio conferencing | Yes |
| Control of other room devices | Yes |
| Hardware video conferencing | No |
| Lighting and shading control | No |
| Room reservation | No |
| Room partition | No |

## Display

- 70-inch commercial display, wall mounted
- Power and input control over TCP/IP

## Sources

- HDMI and Mini DisplayPort at the boardroom table
- Room PC behind the display
- Wireless presentation system with two transmitters and a storage tray
- Streaming devices: Roku and Chromecast
- Cable TV receiver, extended from the rack room and controlled by IR

## Audio

- Q-SYS Core 110f with Named Control integration
- Multi-channel 70 V amplifier
- Six in-ceiling speakers
- Bluetooth wall interface for phones and laptops, with a named device
- Separate levels for content, telephone, PC and Bluetooth audio

## Microphone and conferencing

- One ceiling array microphone over Dante
- Privacy mute from the touch panel
- Softphone on the Q-SYS core for IP dialing
- USB bridge connecting room audio to the PC

## Camera

- One PTZ camera above the display, USB video to the room PC
- IP control for pan, tilt, zoom and presets

## Control

- Crestron CP3 processor in the equipment rack
- 10-inch TSW-1060 touch panel on the table
- Home page options: Source, Audio Conference and Television
- Utility pages: Advanced Audio, Bluetooth, Camera Controls and Assistance
- One-touch system power with an automatic shutdown countdown

## Equipment rack

- Control processor, audio DSP, amplifier and managed network switch
- UPS, power distribution, lacing bars and cable management

## Owner-supplied items

- Room PC
- Cable TV receiver and service
- Streaming devices
- SIP phone service

## Services

- Control system programming
- Audio DSP programming
- Touch panel design
- Installation and commissioning
